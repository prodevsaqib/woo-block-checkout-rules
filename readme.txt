Build conditional rules for WooCommerce checkout without editing code.

== Description ==

Woo Block Checkout Rules provides a simple rule builder for WooCommerce Cart and Checkout Blocks and classic shortcode checkout.

Version 0.1.1 supports conditional additional checkout fields, conditional Cart and Checkout button labels, and declares HPOS compatibility.

WooCommerce must be installed and active for this plugin to work.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it through the WordPress Plugins screen.
3. Go to WooCommerce > Checkout Rules.
4. Add and publish a rule.
